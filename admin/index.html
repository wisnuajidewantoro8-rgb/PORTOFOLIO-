Panel Admin

Masuk dengan GitHub token untuk mengedit isi portofolio. Perubahan disimpan langsung ke repository dan tampil di situs sekitar 1 menit kemudian.

Cara membuat token
  1. Buka github.com/settings/personal-access-tokens/new.
  2. Isi nama token, pilih masa berlaku.
  3. Repository access → Only select repositories → pilih repo portofolio ini saja.
  4. Permissions → Repository permissions → Contents → Read and write.
  5. Klik Generate token, salin, tempel di atas.

Jangan bagikan token ke siapa pun. Token hanya disimpan di browser ini.
